# 3D Viewer

Простой просмотрщик 3D моделей на C++ с использованием OpenGL и GLFW.

## 📋 Описание

3D Viewer - это приложение для просмотра трехмерных моделей, построенное на современном C++ и OpenGL. Проект использует библиотеки GLFW для создания окна и обработки ввода, GLM для математических операций и OpenGL для рендеринга.

## 🚀 Сборка и запуск

### Требования
- CMake 3.31 или выше
- Компилятор с поддержкой C++23
- OpenGL 3.3+

### Инструкция по сборке

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd 3d-viewer

# Создание папки для сборки
mkdir build
cd build

# Конфигурация и сборка
cmake ..
make

# Запуск приложения
./main
```
